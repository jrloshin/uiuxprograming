# 퇴근메이트

오늘 해야 할 일을 정리하고, 남은 업무를 확인하는 직장인용 웹페이지입니다.

- 저장소: https://github.com/jrloshin/uiuxprograming
- 웹페이지: https://jrloshin.github.io/uiuxprograming/

## 기본 이용 방법

업무 내용과 우선순위를 입력하고 확인 버튼을 누릅니다.
확인 화면에서 내용을 수정하거나 등록할 수 있습니다.
등록한 업무는 목록에 표시되고, 끝낸 일은 체크할 수 있습니다.

수정하기를 누르면 입력했던 내용이 유지됩니다.
등록을 취소하거나 다른 업무를 등록할 때는 입력칸이 초기화됩니다.

## 추가한 기능

업무를 등록하고 완료 여부를 체크한 다음 사용할 수 있는
'퇴근 준비 점검' 기능을 추가했습니다.
퇴근 전에 남은 일이 있는지 확인하는 용도입니다.

점검 버튼을 누르면 확인 화면이 나오고,
'점검 결과 보기'를 누르면 업무의 완료 상태에 따라 결과가 달라집니다.

- 등록한 업무가 없으면 먼저 업무를 등록하라는 안내가 나옵니다.
- 끝내지 않은 업무가 있으면 남은 개수와 업무 내용을 보여줍니다.
- 모두 완료했으면 퇴근 준비 완료 문구가 나옵니다.
- 결과 화면에서 업무 목록으로 돌아가거나 다시 점검할 수 있습니다.
- 점검을 취소해도 등록한 업무와 완료 체크는 유지됩니다.
- 업무를 추가하거나 완료 체크를 바꾸면 이전 점검 결과는 숨겨집니다.

## 입력 오류 처리

업무 내용은 앞뒤 공백을 제외하고 2~60자로 입력하도록 했습니다.
내용이 비어 있거나 우선순위를 선택하지 않으면
무엇을 입력해야 하는지 안내합니다.
같은 업무를 중복으로 등록하려고 할 때도 안내가 나옵니다.

## 직접 확인한 내용

PC 브라우저에서 다음 내용을 확인했습니다.

1. '크루 교육 준비'를 우선순위 '높음'으로 등록하니 목록에 표시됐습니다.
2. 완료 체크 전 점검하니 남은 업무가 1개라고 나오고 업무 내용도 표시됐습니다.
3. 완료 체크 후 다시 점검하니 전체 업무 완료 안내가 나왔습니다.
4. 내용을 입력하지 않고 확인 버튼을 누르니 오류 안내가 나왔습니다.
5. 확인 화면에서 수정하기를 누르니 입력한 내용이 유지됐습니다.
6. 내용을 수정한 뒤 등록을 취소하니 입력칸이 비워지고 목록에도 추가되지 않았습니다.
7. 점검을 취소해도 기존 업무와 완료 체크가 유지됐습니다.
8. 브라우저 창을 좁혔을 때 입력창과 목록이 위아래로 배치되고 잘리지 않는 것을 확인했습니다.
9. 배포된 웹페이지에서도 업무 등록, 완료 체크, 퇴근 준비 점검이 동작했습니다.

실제 휴대폰에서는 아직 확인하지 않았습니다.

## 파일 구성

- index.html: 웹페이지 내용과 입력 화면
- style.css: 디자인과 화면 크기에 따른 배치
- script.js: 업무 등록, 입력 검사, 완료 체크, 퇴근 점검

## 참고 사항

업무는 현재 화면을 사용하는 동안만 유지됩니다.
새로고침하거나 페이지를 닫으면 초기화됩니다.
