# 퇴근메이트

오늘 해야 할 일을 정리하고 끝낸 업무를 확인하는 직장인용 서비스입니다.

- GitHub: https://github.com/jrloshin/uiuxprograming
- 배포 주소: https://jrloshin.github.io/uiuxprograming/
- 위 주소는 기존 사이트 주소입니다. 수정 파일을 저장소에 올리고 GitHub Pages 배포가 끝나야 변경 내용이 보입니다.

## 7주차에 구현한 흐름
업무 내용과 우선순위 입력 → 입력 내용 확인 → 등록 완료 → 업무 목록에서 완료 체크

업무는 앞뒤 공백을 제외하고 2~60자로 입력합니다. 빈 입력, 우선순위 누락, 같은 업무 중복 등록은 안내 문구를 표시합니다. 확인 화면에서 수정하기를 누르면 입력값이 유지됩니다. 등록 취소와 다른 업무 등록하기는 입력 상태를 초기화합니다. 우선순위가 높은 업무부터 표시합니다.

## 중간고사에서 추가한 기능
등록한 업무의 완료 상태를 검사하는 '퇴근 준비 점검' 기능을 추가했습니다.

기존 업무 등록과 완료 체크 이후에 사용합니다. '퇴근 준비 점검하기'를 누르고 확인 화면에서 '점검 결과 보기'를 누르면 현재 업무 목록을 검사합니다.

- 업무가 없으면: 점검할 업무가 없다고 안내하고 업무 등록으로 연결합니다.
- 미완료 업무가 있으면: 남은 개수와 업무 이름, 우선순위를 보여주고 업무 목록으로 연결합니다.
- 모두 완료했으면: 완료한 개수와 퇴근 준비 완료 안내를 보여줍니다.
- 점검 취소: 확인 화면을 닫으며 기존 업무와 완료 상태는 유지합니다.
- 다시 점검하기: 이전 결과를 숨기고 확인 단계부터 다시 시작합니다.
- 업무를 추가하거나 완료 상태를 바꾸면: 이전 점검 결과를 숨깁니다. 변경된 상태로 다시 점검할 수 있습니다.

## 파일 구성
- index.html: 소개, 업무 입력/확인/완료 화면, 업무 목록, 점검 화면
- style.css: 화면 스타일과 모바일 배치
- script.js: 입력 검사, 화면 전환, 업무 상태 및 점검 결과 처리

## 확인 기록
개발 환경에서 JavaScript 문법과 아래 16개 동작을 DOM 모의 환경으로 검사했습니다. 모두 통과했습니다. 실제 브라우저 클릭 및 모바일 레이아웃 검증과는 구분합니다.

| 검사 | 확인 결과 |
| --- | --- |
| 등록 전 점검 | 업무 없음 분기 |
| 빈 내용 등록 | 입력 오류 안내 |
| 우선순위 누락 | 선택 안내 |
| 정상 입력 | 확인 화면에 입력값 반영 |
| 수정하기 | 입력값 유지 |
| 업무 등록 | 목록에 추가 |
| 다른 업무 등록 | 입력 초기화 |
| 중복 업무 등록 | 중복 안내 |
| 등록 취소 | 입력 초기화 |
| 점검 취소 | 업무 목록 유지 |
| 미완료 상태 점검 | 미완료 결과 |
| 남은 업무 표시 | 입력한 업무 이름 반영 |
| 완료 상태 변경 | 기존 점검 결과 숨김 |
| 전체 업무 완료 후 점검 | 성공 결과 |
| 다시 점검 | 확인 화면으로 초기화 |
| 완료 체크 해제 | 완료 개수 감소 |

## 업로드 후 브라우저에서 확인할 내용
이 환경에서 실제 브라우저 실행 도구를 준비하지 못해 아래 항목은 아직 확인하지 못했습니다. 제출 전 직접 실행한 뒤 실제 결과로 이 항목을 갱신합니다.

1. 데스크톱에서 업무 등록부터 퇴근 점검까지 진행합니다.
2. 빈칸, 우선순위 누락, 미완료 업무, 등록 취소, 점검 취소, 수정 경로를 실행합니다.
3. 휴대폰 또는 브라우저의 모바일 모드에서 버튼과 입력창을 조작하고 가로 넘침을 확인합니다.
4. GitHub Pages 주소에서 새 화면과 기능이 반영됐는지 확인합니다.

업무 정보는 현재 페이지의 메모리에만 있습니다. 새로고침하거나 페이지를 닫으면 초기화됩니다. 로그인, 서버 저장, 실제 회사 시스템 연동은 구현하지 않았습니다.
